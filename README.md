# Retail Sales & Customer Analytics Using Python

## 📊 Project Overview

This repository contains an end-to-end **Business Analytics project** focused on analysing retail sales and customer transaction data using Python.

The project was completed as part of the **Junior Data Analyst – Business Analytics with Python internship at YuvaIntern**. The six-week project follows a complete business analytics workflow, progressing from business strategy and data preparation to visualization, statistical analysis, predictive modeling, interactive dashboard development, and final business recommendations.

The project demonstrates how raw transactional data can be transformed into reliable analytical information and practical business insights using Python-based analytics techniques.

---

## 🎯 Project Objectives

The project aims to transform retail transaction data into meaningful business insights by analysing:

- 📈 Sales performance and revenue trends
- 🛍️ Product performance and purchasing patterns
- 👥 Customer and transaction behaviour
- 🌍 Geographic sales performance
- 🧹 Data quality and transaction anomalies
- 📊 Statistical relationships and hypothesis testing
- 🤖 Predictive modeling and sales forecasting
- 📋 Interactive business intelligence dashboards
- 💡 Data-driven business recommendations

---

## 📂 Dataset

The project uses the **Online Retail dataset** from the **UCI Machine Learning Repository**.

The original dataset contains **541,909 transaction records** and information including:

- Invoice number
- Stock code
- Product description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country

The dataset represents transactions from a UK-based registered non-store online retailer.

> **Note:** The original raw dataset is publicly available through the UCI Machine Learning Repository. Large raw data files are not stored directly in this repository.
